# 二、需求背景

用户知道要完成什么业务动作，却未必记得算子名称。当前约 600 个基础算子，预计一年内不超过 2000；Flow 数量另算，不能套用算子规模估计。已有用途整理稿仍需核验和回填。

主要用户为项目内编排人员。算子检索服务于灵活编排；Flow 检索服务于在已有方案上小步修改。两者在同一添加面板内分别检索，避免用户在混合列表中判断不同对象和操作。

不同检索方式耗时不同。等待全部完成会拖慢简单查找，后到结果插入或重排又会造成误点。本次先呈现可用结果，补充结果独立分区；本期按功能场景验收，不新增专门收益埋点。

# 四、详细说明

## 4.1 核心业务流程

- 添加算子：打开“添加节点”或节点／连线“＋”，选择“找算子” → 查看历史连接推荐或输入用途 → 直接匹配立即出现 → 自动补充相关用途 → 按需深入搜索 → 查看依据并点击添加，或拖入画布落点。
- 复用 Flow：打开“添加节点”，选择“找 Flow” → 描述整体目标及希望修改的地方 → 分层查看候选 → 查看步骤、版本及与目标的差异 → 基于所选版本新建自己的草稿，保留来源；可直接拖入当前画布作为节点组，详情另保留“作为节点组添加”。

## 4.2 功能详细说明

| **序号** | **模块** | **功能** | **功能详细说明** | **用户故事** | **交互/原型图** |
| --- | --- | --- | --- | --- | --- |
| 1 | 算子检索 | 按用途搜索 | **操作与系统响应：**统一“添加节点”及局部“＋”打开检索面板，默认“找算子”，可切换“找 Flow”；算子页仅检索基础算子；输入“去掉重复数据”等业务说法，先显示文字匹配，再独立补充同义、近义候选。统一读取算子地图，展示名称、ID、简介及匹配依据。 **系统记录：**保存真实身份、实际版本和依据；用途、别名及适用条件从核验后的整理稿回填，不另建在线权威目录。 **异常：**无匹配、查询失败和资料缺失分别显示；无历史不影响检索。 **完成标准：**可通过用途找到陌生名称的算子，点击添加或拖入画布落点，拖入后面板保持打开。 | 作为编排人员，我希望用业务说法查找算子，以便灵活编排不熟悉名称的已有能力。 | 添加算子／相关用途分区／详情与添加 |
| 2 | 直接匹配 | 名称 ID 与关键词查找 | **操作与系统响应：**输入完整名称、ID、别名、关键词或近似拼写，立即执行文字检索，不等待向量和模型；完整身份精确命中优先。算子与 Flow 分别检索，同名对象显示身份及版本。 **系统记录：**保留检索对象、查询、过滤条件、请求身份及命中字段；正则属于内部匹配实现，不要求用户编写表达式。 **异常：**未命中不能提前宣称全部检索无结果；无权对象不泄露。 **完成标准：**直接结果可在自动补充未完成时查看和操作。 | 作为熟悉能力的用户，我希望快速定位名称或 ID，以便不为简单查找等待深度分析。 | 分类检索页签／直接匹配分区 |
| 3 | 分层检索 | 自动相关用途补充 | **操作与系统响应：**有查询时自动补充相关用途，目标 2 秒内返回；显示独立阶段状态，结果进入下方独立分区，已显示的候选不得自动重排、前插或被重复铺出。 **系统记录：**保留各阶段状态、耗时、结果身份及当前请求身份；向量与文字召回可并行。 **异常：**超出自动等待预算、失败及无结果分别提示并支持重试，直接结果保持可用；改词、换类型、改过滤或关闭入口使旧请求失效。 **完成标准：**慢结果出现时快结果的位置、焦点与滚动位置稳定，旧查询不回填。 | 作为编排人员，我希望先使用快结果并看到后续补充，以便兼顾速度和漏检而不误点。 | 同一面板上下分区／等待与重试 |
| 4 | 深入检索 | 用户主动判断适用性 | **操作与系统响应：**用户主动“深入搜索”后，结合授权候选和完整资料补充遗漏、判断适用性并解释依据；允许 5 秒或更久，显示真实阶段和耗时，随时可取消，已有结果继续可用。 **系统记录：**保存所用资料身份与版本、分析请求和阶段；不逐次读取全量历史 Flow，不自动修改流程。 **异常：**资料不足如实说明；失败可重试；取消和旧请求不得继续写入结果；不编造进度百分比或把 5 秒作为上限。 **完成标准：**用户能理解候选是否适合当前用途，已有候选只补充分析引用、不重复生成候选卡片。 | 作为编排人员，我希望主动花更多时间判断适用性，以便在初步结果不明确时选对已有能力。 | 深入搜索分区／取消／依据与限制 |
| 5 | Flow 复用 | 按整体目标及改动找方案 | **操作与系统响应：**面板内选择“找 Flow”，仅检索授权、已发布的可复用 Flow；同时理解整体目标及希望改动的地方，展示简介、步骤、版本及有资料支持的差异。 **系统记录：**Flow 按整体目标、实际步骤、配置及适用条件组织；同一 Flow 多版本集中查看，不混入基础算子列表。 **异常：**未描述改动时仍可按用途查找；不能根据一个步骤命中就宣称整套方案适用；未知差异明确待核对。 **完成标准：**用户能找到接近目标的已有方案并查看需要核对或修改的位置。 | 作为编排人员，我希望找到接近目标的 Flow 并了解差异，以便在已有方案上小步迭代。 | 复用 Flow／分层结果／版本及步骤详情 |
| 6 | Flow 复用 | 基于指定版本新建草稿 | **操作与系统响应：**主操作为“基于此版本新建草稿”，复制所选版本的实际节点、连线及配置，生成独立草稿和节点身份；保留来源 Flow ID 与版本，可返回原草稿。支持将结果拖入当前画布落点作为节点组，详情保留“作为节点组添加”次要操作；拖入不创建新草稿、不替换当前流程、不自动改动已有连线。 **系统记录：**保存新草稿身份、来源身份及所选版本；保留原草稿内容、未保存配置及上下文。 **异常：**来源撤权或停用时阻止复用；不得覆盖当前画布、误用最新版本或把建议改动自动应用；新草稿不继承旧试跑和诊断记录。 **完成标准：**所选版本与创建内容一致，节点可编辑，返回原草稿后内容和未保存配置完整。 | 作为编排人员，我希望基于指定 Flow 创建自己的修改版，以便安全迭代并保留原方案。 | Flow 详情／新建草稿／返回原草稿／节点组添加 |
| 7 | 血缘推荐 | 历史连接推荐 | **操作与系统响应：**无搜索词且有上游上下文时展示有历史连线依据的候选及简短理由；有用途查询时用途优先、血缘辅助。无上下文显示可浏览目录，不伪造推荐。 **系统记录：**关联真实前后节点、端口、来源工作流及版本；组推荐追溯实际组实例，关系预先提取。 **异常：**无血缘仍可检索；仅同流程共现不算连接事实；推荐不可用时提示并保留授权检索。 **完成标准：**理由可追溯，重复发布、执行或已知复制不虚增独立采用次数。 | 作为编排人员，我希望了解已有流程常接什么能力，以便减少下一步的查找成本。 | 算子无查询推荐／查看连接依据 |
| 8 | 访问控制 | 权限与可用性过滤 | **操作与系统响应：**检索、排序、详情、模型资料、血缘理由及复用仅使用当前项目及平台公开的授权资料；添加和新建时再次复核可用状态。 **系统记录：**保留目录与连接的项目、可见范围和可用状态。 **异常：**其他项目私有资料不得参与；停用或撤权的旧结果禁止添加及新建；失败不能冒充无结果。 **完成标准：**各阶段均不越权，旧候选无法绕过最终校验。 | 作为项目成员，我希望只看到可使用的能力，以便避免误用或泄露私有方案。 | 各阶段结果／详情／复用前校验 |

## 4.3 关键规则

| 规则 | 说明 |
| --- | --- |
| 历史依据 | 草稿、试跑不累计正式采用；正式执行关系优先于仅发布关系。连接采用与执行次数分开，同一来源未变连接不因版本或参数变化重复累计。 |
| 推荐边界 | 曾衔接不代表运行成功或质量达标；不自动补前置节点。 |
| 检索入口 | 统一“添加节点”入口，面板内“找算子／找 Flow”分别检索并保存独立查询和过滤状态，切换时不继承另一类型的慢请求；顶部不新增“复用 Flow”按钮。 |
| 拖放 | 算子拖入落点生成节点；Flow 拖入落点按所选版本生成节点组，保留来源身份和版本。拖后面板保持打开，已有节点和视角不自动移动；点击局部添加仍按原上下游上下文接线，拖入空白画布不沿用该上下文改线。 |
| 防跳位 | 分层区域按顺序呈现；补充阶段仅更新自身区域，不改变上方结果高度、顺序、焦点和滚动位置。用户主动展开详情或切换查询可改变布局。 |
| 深入结果 | 可引用已展示候选补充判断；新发现候选只在深入区出现，稳定身份去重。 |
| 原型边界 | 本地文字匹配读取本地资料；用途和深入阶段为规则驱动演示，边界在交付文档标注，界面不放演示开关、阶段选择、权限模拟或报错示例入口，无真实向量和模型调用。权限、发布状态和来源关系为样例，不能作为生产验收证据。 |

## 4.4 检索方案与真实效果验收

先核验知识，再以相同业务查询对照“文字匹配”与“文字加轻量向量”，记录漏检改善、延迟、调用成本和维护成本；生产是否接入向量依据对照结果另行决策，不以 600 个算子的规模替代判断，也不预设独立向量数据库。在线模型仅由用户主动深入触发。实际向量服务、模型能力及超时配置待研发评审，不用演示等待时长承诺生产性能。

本地验收覆盖：快慢结果独立、分区去重、连续改词和关闭后旧请求失效、自动超时、深入取消及重试、空结果、权限与停用模拟、指定版本新建、原草稿恢复、算子及指定版本 Flow 拖放、拖后面板保持打开、撤销重做、节点组添加和既有字段映射及诊断回归；异常注入通过测试完成，不放入业务界面。真实资料检索质量、真实权限和生产速度需另行集成验收。

# 五、非功能需求

查询失败与无结果须可区分；自动补充目标 2 秒，主动深入允许 5 秒或更久，最终运行超时按真实服务能力评审。已有结果保持可操作。复用现有权限和添加能力，不因索引滞后绕过权限或停用检查。支持键盘焦点、动态状态播报和减少动效；阶段更新不得抢焦点。
